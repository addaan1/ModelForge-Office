# Manual Kaggle Data Drop

Taruh file kompetisi di folder ini kalau ingin mencoba tanpa Kaggle CLI:

```text
train.csv
test.csv
sample_submission.csv
*.zip
```

Untuk kompetisi sungguhan, sebaiknya ganti `manual-project` dengan slug kompetisinya, misalnya:

```text
data/competitions/playground-series-s6e5/raw
```
